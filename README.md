# Farm Fresh MVP

Build a complete GitHub-ready MVP called FARM TO TABLE using React + TypeScript + Vite + Tailwind CSS + Supabase.

Create everything in one generation.

Pages:

Landing

Login

Register

Farmer Dashboard

Consumer Dashboard

Marketplace

Add/Edit Product

Product Details

Purchase Requests

Profile

Features:

Farmer and Consumer roles

Supabase Authentication

CRUD for produce listings

Search, filter, and sort products

Purchase request system

Dashboard cards

Responsive UI

Green agriculture theme



## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
